توضّح هذه الصفحة كيف يتعامل برنامج Iris (من DataX Matrix) مع بيانات المدرسة والطلاب والموظفين.

أين تُحفظ البيانات

  • تُحفظ كل بيانات البرنامج على جهاز المدرسة فقط، في قاعدة بيانات مشفّرة.
  • لا نجمع أي بيانات، ولا تُرسل بيانات الطلاب أو الموظفين أو المالية إلينا ولا إلى أي طرف ثالث.
  • المدرسة هي صاحبة البيانات والمسؤولة عنها، ويمكنها حذفها في أي وقت.

النسخ الاحتياطي

  • النسخ الاحتياطي اختياري، وتختار المدرسة مكانه: وحدة USB، أو حساب OneDrive الخاص بالمدرسة.
  • النسخ إلى OneDrive لا يعمل إلا إذا فعّلته المدرسة. يُشفَّر ملف النسخة داخل Iris قبل أن يغادر الجهاز، ثم يُحفظ في حساب Microsoft الخاص بالمدرسة نفسها، وتسري شروط Microsoft على هذا التخزين.
  • نحن (DataX Matrix) لا نستلم هذه النسخ أبداً.

الاتصال بالإنترنت

  • يعمل البرنامج بدون إنترنت.
  • الاتصال الوحيد الذي يجريه البرنامج هو فحص اختياري للتحديثات من dataxmatrix.com: طلب HTTPS عادي لملف عام، لا يُرسل فيه أي بيانات شخصية أو بيانات مدرسية.
  • كأي موقع على الإنترنت، قد يسجّل مزوّد الاستضافة (GitHub Pages) بيانات تقنية مثل عنوان IP للجهاز.
  • يمكن تجنّب هذا الاتصال بإبقاء الجهاز دون إنترنت.

التفعيل

التفعيل يتم بدون إنترنت، بتبادل رموز: ترسل المدرسة رمز الطلب إلينا عبر واتساب باختيارها، ونرسل لها رمز التفعيل. رمز الطلب يحتوي على بصمة للجهاز، ولا يحتوي على أي بيانات للطلاب. ما تكتبه لنا في واتساب (مثل اسم المدرسة) نستخدمه للتفعيل والدعم فقط.

هذا الموقع

موقع dataxmatrix.com لا يستخدم ملفات تعريف الارتباط (cookies) ولا أدوات تتبّع أو إحصاء. يحفظ المتصفح فقط اختيارك للوضع الليلي.

Privacy Policy — English summary

Iris is a school management desktop app for Windows by DataX Matrix. Last updated: 17 October 2026.

  • Local storage only. All data (students, staff, attendance, finance) is stored only on the school's computer, in an encrypted database.
  • No data collection. We do not collect any data. No data is sent to us or to any third party.
  • Optional backups. Backups go only where the school chooses: a USB drive or the school's own OneDrive account. OneDrive backup runs only if the school turns it on; the backup file is encrypted inside Iris before it leaves the computer and is stored in the school's own Microsoft account, where Microsoft's terms apply. We (DataX Matrix) never receive it.
  • Network use. The only network request the app makes is an optional update check to dataxmatrix.com: a standard HTTPS request for a public file. It sends no personal or school data. Like any website, the hosting provider (GitHub Pages) may log technical data such as the IP address. It can be avoided by keeping the computer offline.
  • Offline activation. Activation is an offline code exchange. The school chooses to send us a request code via WhatsApp and receives an activation code. The request code contains a device fingerprint, not student data. What the school writes to us on WhatsApp (such as the school name) is used only for activation and support.
  • This website uses no cookies, analytics or tracking.
  • Changes. If anything changes in how Iris handles data, we will update this page and its "Last updated" date.
