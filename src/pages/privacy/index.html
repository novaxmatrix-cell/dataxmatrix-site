أين تُحفظ البيانات

  • تُحفظ كل بيانات البرنامج على جهاز المدرسة فقط، في قاعدة بيانات مشفّرة.

  • المدرسة هي صاحبة البيانات والمسؤولة عنها، ويمكنها حذفها في أي وقت.

النسخ الاحتياطي

  • النسخ الاحتياطي اختياري، وتختار المدرسة مكانه: وحدة USB، أو حساب OneDrive الخاص بالمدرسة.
  • النسخة على OneDrive تُحفظ في حساب المدرسة نفسها، ولا نستطيع الوصول إليها. ويخضع OneDrive لسياسة الخصوصية الخاصة بـ Microsoft.

الاتصال بالإنترنت

  • يعمل البرنامج بدون إنترنت.
  • الاتصال الوحيد الذي يجريه البرنامج هو فحص اختياري للتحديثات من dataxmatrix.com، ولا يُرسل فيه أي بيانات شخصية أو بيانات مدرسية. وكأي طلب على الإنترنت، قد يرى مزوّد الاستضافة عنوان IP للجهاز.

موقع dataxmatrix.com لا يستخدم ملفات تعريف الارتباط (cookies) ولا أدوات تتبّع أو إحصاء. يحفظ المتصفح فقط اختيارك للوضع الليلي.

Privacy Policy — English summary

Iris is a school management desktop app for Windows by DataX Matrix. Last updated: 17 October 2026.

  • Local storage only. All data (students, staff, attendance, finance) is stored only on the school's computer, in an encrypted database.
  • No data collection. We do not collect any data. No data is sent to us or to any third party.
  • Optional backups. Backups go only where the school chooses: a USB drive or the school's own OneDrive account. We have no access to these backups; OneDrive is covered by Microsoft's privacy policy.
  • Network use. The only network request the app makes is an optional update check to dataxmatrix.com. It sends no personal or school data. As with any web request, the hosting provider may see the device's IP address.
  • Offline activation. Activation works without internet: the school sends us a request code via WhatsApp and receives an activation code.
  • This website uses no cookies, analytics or tracking.
