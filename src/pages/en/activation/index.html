Activation questions

We changed computers. Do we need a new activation?

Yes. Send us the new request code from the new computer and we’ll activate it for you.

Does activation need an internet connection?

No. You send the request code from any phone, and enter the activation code in Iris without internet. The yearly renewal code is checked offline the same way.
