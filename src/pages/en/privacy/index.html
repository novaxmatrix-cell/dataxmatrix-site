Privacy policy

Your school’s data stays at your school.
Last updated: 17 October 2026

This page explains how Iris, a Windows school management app by DataX Matrix, handles the data of the school, its students and staff.

Where the data is stored

  • All of Iris’s data is stored only on the school’s computer, in an encrypted database.
  • We do not collect any data. Student, staff and financial data is never sent to us or to any third party.
  • The school owns its data and is responsible for it, and can delete it at any time.

Backups

  • Backups are optional, and the school chooses where they go: a USB drive or the school’s own OneDrive account.
  • OneDrive backup runs only if the school turns it on. The backup file is encrypted inside Iris before it leaves the computer, then stored in the school’s own Microsoft account, where Microsoft’s terms apply to that storage.
  • We (DataX Matrix) never receive these backups.

Internet connection

  • Iris works without internet.
  • The only network request Iris makes is an optional update check to dataxmatrix.com: a standard HTTPS request for a public file, which sends no personal or school data.
  • Like any website, the hosting provider (GitHub Pages) may log technical data such as the computer’s IP address.
  • This request can be avoided by keeping the computer offline.

Activation

Activation works without internet, as a code exchange: the school chooses to send us its request code on WhatsApp, and we send back an activation code. The request code contains a device fingerprint and no student data. What you write to us on WhatsApp (such as the school’s name) is used only for activation and support.

This website

dataxmatrix.com uses no cookies and no tracking or analytics tools. Your browser only stores your dark mode and language choices.

Changes to this policy

If anything changes in how Iris handles data, we will update this page and the “Last updated” date at the top.
