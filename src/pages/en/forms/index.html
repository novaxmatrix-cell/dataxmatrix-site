Frequently asked questions

Does Iris need internet?

No. It runs entirely on the school’s computer; the internet is only used to download new versions.

Where is the school’s data stored?

Only on the school’s computer, with an automatic backup to a USB drive.

We changed computers. Do we need a new activation?

Yes. Contact us with the new request code and we’ll activate it for you. Activation steps

A blue Windows message appeared during installation. What should I do?

Press “More info”, then “Run anyway”. The message appears because the program is new. Always download Iris from the download page only.
