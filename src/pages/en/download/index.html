Installation steps

Installation takes about two minutes on the school’s computer.

Open the Store page

Press “Download from the Microsoft Store” above. The Microsoft Store opens on the Iris page.

Install Iris

Press the install button in the Store. Windows downloads and installs Iris by itself.

Open Iris

Iris appears in the Start menu. Open it from there.

Activate Iris

Follow the activation steps.

Moving from the direct installer

Earlier versions of Iris were installed from a setup file. They no longer receive updates. Move to the Microsoft Store version:

  1. Before moving, make a backup from inside Iris.
  2. Uninstall the old Iris from Windows Settings → Apps.
  3. Install Iris from the Microsoft Store (steps above), open it, then restore the backup.
Never install both versions on the same computer. If your data does not appear, contact us on WhatsApp.
