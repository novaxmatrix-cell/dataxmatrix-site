Installation steps

Installation takes about two minutes on the school’s computer.

Open the Store page

Press “Download from the Microsoft Store” above. The Microsoft Store opens on the Iris page.

Install Iris

Press the install button in the Store. Windows downloads and installs Iris by itself.

Open Iris

Iris appears in the Start menu. Open it from there.

Activate Iris

Follow the activation steps.

Direct installer

The same Iris as a setup file, for computers without the Microsoft Store.

{{DOWNLOAD_BOX}}
  1. Download the setup file and double-click it.
  2. If the blue Windows message “Windows protected your PC” appears, press “More info”, then “Run anyway”. It appears because the installer is new, not because it is unsafe.
  3. Follow the steps to the end, then activate Iris.
Never install both versions on the same computer. To move to the Store version, first uninstall the normal Iris from Windows Settings → Apps. The school’s data is kept.
