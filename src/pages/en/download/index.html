Installation steps

Installation takes about two minutes on the school’s computer.

Download the file

Press the download button above and save the setup file on the computer.

Run the setup file

Double-click the file. If the blue Windows message “Windows protected your PC” appears, press “More info”, then “Run anyway”.

Finish the installation

Follow the steps to the end. Iris will appear on the desktop and in the Start menu.

Activate Iris

Open Iris and follow the activation steps.

The blue Windows message appears because the program is new, not because it is unsafe. Always download Iris from this page only.
